## Numeric acceptance tolerances

Unit projection is display-only. Canonical temperatures remain in degrees Celsius.

- Celsius to Fahrenheit display: `F = C * 9 / 5 + 32`
- Fahrenheit input to canonical Celsius: `C = (F - 32) * 5 / 9`
- Round-trip canonical temperature tolerance: `±0.01 °C`
- Display round-trip tolerance: `±0.05 °C`
- Capacity, COP, EER, humidity ratio, enthalpy and mass-flow invariance: absolute difference `<= 1e-9` before display formatting
- Displayed engineering results: identical at the existing displayed precision

## Result contract

Every corrected result surface consumes one status contract:

```text
{ status: valid | warning | blocked, value: finite-number | null, reason: string | null }
```

Rules:

- `blocked` implies `value = null`.
- Blocked cards render `—`, never `0.0000` or `0 ± 0`.
- Dependent charts do not render coordinates unless every required value is finite.
- Charts consume the same evaluated state/result values used by cards and exports; they do not recompute a parallel result path.
- Save/export controls are disabled when their result contract does not permit persistence, and the blocking reason remains visible.

## Stop conditions

Stop and do not open a release-ready PR if:

- any protected source file changes;
- behavioral golden vectors move unexpectedly;
- a chart or output surface uses a separate formula path;
- unit round-trip changes physical results;
- either fixed COP card is mode-dependent;
- blocked state emits console errors or numeric-zero placeholders;
- deterministic build, exact-SHA reporting, Node tests or browser gates fail;
- the generated A/A and A/L byte anchors are not replaced and documented in the same reviewed change.
